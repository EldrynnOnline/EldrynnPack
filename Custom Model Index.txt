Hard replacement items will be OVERIDING the original model and thus DO NOT need a custom command to summon
This only effects former ALTERNATIVE models which now can be attached to ANY item


You can summon ANY listing below on any item via the command:

(replace every pair of <> and their contents)
/minecraft:give @s minecraft:<item>[minecraft:item_model="<any below listed entry>"] 1

(for the dyed wizard hat specifically, Minecraft dyes use decimal versions of hexcode colors so a brief google "hexadecimal to decimal" should help.. or use mc stacker)
/minecraft:give @s minecraft:carved_pumpkin[minecraft:item_model="custom:dyedwizardhat",minecraft:dyed_color=<color>]
